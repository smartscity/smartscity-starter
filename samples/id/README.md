# Distributed ID examples

This unpublished Maven aggregator groups the two executable applications:

| Directory | Application |
|---|---|
| `id-example` | Spring Boot 2.7/3 with `smartscity-starter-id` |
| `id-example-boot4` | Spring Boot 4 with `smartscity-starter-id-boot4` |

Each application owns its standard Maven source tree. See [sample commands](../README.md) and the [canonical ID guide](../../docs/id/USER_GUIDE.md) for schema initialization, environment variables and configuration. The root `samples` profile selects this family.
