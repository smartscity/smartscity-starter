# ID 契约

实现依据：[已批准方案](proposals/id-v1/README.md)。API：`IdGenerator.getUniqueId()`、`parse(long)`、`snapshot()`、`close()`。

- 返回正数 long；时间为生成时刻。并发完成顺序、跨实例顺序不保证递增。
- 默认等待 10ms；缓存耗尽或领取竞争共用一次调用预算，超时为 `TIMEOUT`。中断保留标记并返回 `INTERRUPTED`。
- 时间异常、Worker 失效、关闭立即拒绝新调用。已在途调用不能被原子撤回；失败时已领取的 ID 作废，不放回缓存。
- `IdException.Reason` 提供配置、启动、时钟、容量、等待、协调、关闭及内部故障分类；调用方不解析错误消息。
- `snapshot()` 是只读近似观测；延迟分位数为二次幂桶上界，不是性能验收结果。
- `close()` 幂等；停止本地生产，尽力标记数据库退出并释放 ZK。进程强杀时不保证退出更新。
- 关闭等待生产者最多 1s，ZK 与数据库外部清理共用 `shutdown-timeout`；保留调用方中断标记。取消启动不会取消尚未执行的清理，迟到的结果不会对外启用。
- 同组布局/Epoch 一致；不同组或布局不自动保证裸 ID 互斥。普通档回绕、JS 同秒复用和过期旧实例恢复的边界仍按方案执行。

首版无批量 API；用户可循环调用。内部 TimeSource/WorkerLease 隔离时钟和外部占用，使用内置数据库时无需编写 SPI。
