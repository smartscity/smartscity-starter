# 版本与发布政策

当前版本 `0.1.0-SNAPSHOT` 只标识开发骨架，未发布到 Maven Central 或任何远程制品库。

根 POM 的 `maven.deploy.skip=true` 防止普通生命周期意外尝试部署；当前不配置 distributionManagement、签名或远程凭据。这不代替正式发布审批。

正式发布前必须明确：

- 项目许可证、所有者、SCM、漏洞报告渠道及制品仓库坐标。
- API、ID 编码、Epoch、节点身份、失败语义与兼容矩阵的有效决策。
- 对应版本实际通过的正确性、兼容性、API/架构门禁及可追溯报告。
- 如宣称性能，提供单独授权、完整可复现的性能报告。
- 发布、回滚、签名、BOM 消费验证及变更记录。

采用语义化版本作为后续管理方向；发布后的编码格式和公共契约变更必须有 ADR 与迁移说明。`1.0.0` 的冻结条件等待功能设计确认。

不得将空 JAR、骨架构建成功或候选兼容版本写成正式交付。当前阶段不初始化远程仓库、不提交或发布制品。
