# 测试与门禁

当前验收实现与正确性；实际结果见[门禁记录](../testing/GATE-RESULTS.md)。

1. API/SPI/Core 依赖和 Java 9 字节码符合边界，自动配置注册与生成元数据有效。
2. 三档及 JS 变体的编码边界、秒切换、序列耗尽、回拨、超时、中断和关闭行为通过。
3. CAS 领取与跨圈回收不重复；填充故障、暂停和关闭不能使等待永久挂起。
4. 真数据库校验启动事务、布局冲突、自增和退出；真 ZK 校验占位、断连、恢复和过期。
5. 多进程启动与退出/kill -9、真实数据库停机须单独记录，不以进程内单测替代。
6. 同一产物在核实后的 Boot/JDK 组合验证自动发现、Bean 退让、开关和实际发号；未跑组合保持 NOT_RUN。

数据库测试仅接受显式测试地址，不读取业务环境配置。示例须实际运行。性能测试遵循[独立政策](08-Benchmark.md)，本轮用户明确不运行。
