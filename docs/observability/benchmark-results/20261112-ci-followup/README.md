## Comparison boundary

The earlier [measurement](../20261112/README.md) used an AMD EPYC 9V45; this run used an EPYC 7763. Absolute rates between these hosts are **NOT_COMPARABLE as code-performance changes**. The benchmark JAR SHA-256 is identical in both runs: `0da7a714e413fba2afa9bbfb61e6a3079f228ac720d745188be6b52ca46ad811`. The measured production JAR hashes are also unchanged. No speed regression or improvement is attributed to the test/CI correction.

Within each run, AC and sequential replacement use equal-output synthetic inputs on the same host. The small-dictionary HIT slowdown and allocation cost remain explicit counterexamples to a universal AC speedup. Loopback tests do not establish reliable UDP, collector throughput, long-duration stability or production SLA. The original experiment and failures remain preserved.
